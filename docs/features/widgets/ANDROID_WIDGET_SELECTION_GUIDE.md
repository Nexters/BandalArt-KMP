# Android 위젯 표시 대상 선택 가이드

## 목적

이 문서는 Android 홈 화면 위젯이 어떤 반다라트와 세부 목표를 표시하는지 정하는 현재 기준이다. 위젯 설정 화면의 최초 선택뿐 아니라 앱에서 반다라트와 세부 목표를 바꾼 뒤의 동작도 이 기준을 따른다.

## 반다라트 선택 기준

1. 앱에서 마지막으로 본 반다라트를 표시한다.
2. 마지막 조회 기록이 없으면 해당 위젯의 설정 화면에서 저장한 반다라트를 표시한다.
3. 모든 위젯은 앱의 단일 마지막 조회 기록을 공유한다. 따라서 여러 위젯을 배치해도 표시 반다라트는 함께 바뀐다.

## 세부 목표 선택 기준

표시할 반다라트가 결정되면 아래 우선순위로 세부 목표를 고른다.

1. 해당 반다라트에서 사용자가 마지막으로 열어본 세부 목표
2. 최근 세부 목표 기록이 없는 기존 위젯은 설정 화면에서 저장한 세부 목표
3. 제목이 있는 첫 번째 세부 목표
4. 제목이 있는 세부 목표가 없으면 선택하지 않음

세부 목표를 직접 열었을 때뿐 아니라 그 아래 할 일을 열었을 때도 해당 부모 세부 목표를 최근 항목으로 기록한다. 메인 목표를 여는 동작은 기존 세부 목표 기록을 지우지 않는다.

최근 세부 목표는 반다라트별로 저장한다. 따라서 A 반다라트의 세부 목표를 본 뒤 B로 이동했다가 다시 A로 돌아오면 A에서 마지막으로 본 세부 목표를 복원한다. 앱을 재시작해도 같은 기준을 유지한다.

저장된 세부 목표가 삭제됐거나 제목이 초기화된 경우에는 유효한 최근 항목으로 보지 않고 제목이 있는 첫 번째 세부 목표로 대체한다. 다른 반다라트의 세부 목표 ID는 사용하지 않는다.

## 위젯 설정 화면과의 관계

- 위젯을 처음 추가할 때 사용자가 고른 반다라트와 세부 목표를 최초 최근 항목으로 함께 저장한다.
- 설정값은 마지막 조회 기록이 없는 기존 사용자와 데이터 복구를 위한 fallback으로도 유지한다.
- 설정 이후 앱에서 다른 반다라트나 세부 목표를 보면 최근 항목 기준이 우선한다.

## 갱신 기준

아래 데이터가 바뀌면 설치된 Android 위젯 전체를 갱신한다.

- 반다라트, 세부 목표, 할 일 또는 달성률
- 마지막으로 본 반다라트
- 마지막으로 본 세부 목표

앱 데이터 변경 갱신과 백그라운드 진입 갱신은 직렬로 처리한다. 먼저 읽은 오래된 snapshot이 나중에 끝나 최신 위젯을 덮어쓰지 않아야 한다.

## 검증 기준

- A → B → A 전환 시 각 반다라트에서 마지막으로 본 세부 목표를 복원한다.
- 최근 세부 목표 기록이 없으면 제목이 있는 첫 번째 세부 목표를 선택한다.
- 최근 세부 목표가 삭제되거나 제목이 비면 다음 유효한 세부 목표로 대체한다.
- 유효한 세부 목표가 없으면 세부 목표와 할 일을 표시하지 않는다.
- 앱 재시작 후에도 최근 반다라트와 반다라트별 최근 세부 목표를 복원한다.
- 달성률 변경 갱신과 앱 백그라운드 갱신의 순서가 겹쳐도 마지막 화면에는 최신 달성률이 남는다.
