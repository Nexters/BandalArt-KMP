# iOS iPad 지원 전략

- 작성일: 2026-10-16
- 대상 버전: iOS 1.5.3
- 관련: #434 넓은 화면 표 배치, #447 넓은 화면 시트 inset, #448 완료 화면 넓은 화면 배치

## 결정

- `TARGETED_DEVICE_FAMILY`에 iPad(2)를 더한다: `"1,7"` → `"1,2,7"`
- iPad에서 앱이 종료되는 경로를 먼저 막는다: 공유 시트(`UIActivityViewController`)에 popover 기준 위치를 지정한다
- 화면 배치는 #434의 비율 기반 분기(세로 1단, 가로 2단)와 #447 시트 너비 제한을 그대로 쓰고, iPad에서 깨지는 화면만 고친다
- 완료 화면(#448)은 iPad에서 더 늘어나므로 이 작업에 포함한다

## 배경

- 1.5.x까지 iOS 앱은 iPhone 전용이었다. iPad에서는 iPhone 호환 모드(확대된 iPhone 화면)로만 실행된다.
- #434, #445, #447로 넓은 화면·가로 배치가 생겨 iPad에서도 쓸 만한 기반이 생겼다.

## 되돌리기 어려운 점

| 항목 | 내용 |
|---|---|
| 지원 제거 불가 | App Store에 iPad 지원으로 출시한 뒤에는 업데이트로 iPad 지원을 뺄 수 없다 |
| 심사 자료 | 13인치 iPad 스크린샷이 필수가 된다 |
| 심사 기준 | iPad에서 크래시·잘림이 있으면 심사가 거절된다 |

따라서 아래 확인을 모두 통과한 뒤에만 출시한다.

## 단계

1. 공유 시트 popover 기준 위치 지정 (`ImageHandlerProvider.ios.kt`의 `shareBitmap`, `shareUrl`)
2. `TARGETED_DEVICE_FAMILY` 변경
3. iPad 시뮬레이터 확인 (아래 표). 깨지는 화면은 단계별 커밋으로 고친다
4. 완료 화면 넓은 화면 배치 (#448)
5. 13인치 iPad 스크린샷

## 확인

| 화면 | iPad 세로 | iPad 가로 | Split View·Stage Manager 좁은 창 |
