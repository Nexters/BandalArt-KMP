# 설정 바텀시트 타이포그래피 보정 전략

## 배경

설정 바텀시트는 모든 텍스트에 Pretendard를 지정하지만 자간과 행간을 생략한다. 그 결과 Material 전역 `bodyLarge`의 양수 자간과 24sp 행간이 일부 속성에 남아 기존 반다라트 화면보다 텍스트가 넓고 느슨하게 보인다.

## 목표

- 설정 바텀시트의 글자 크기별 자간과 행간을 명시한다.
- 기존 Pretendard font family와 font weight를 유지한다.
- 전역 `Typography`, Material 컴포넌트, 레이아웃은 변경하지 않는다.

## 적용 값

| 대상 | 크기 | 자간 | 행간 |
| --- | ---: | ---: | ---: |
| 설정 제목 | 20sp | -0.4sp | 28sp |
| 테마 항목 | 16sp | -0.32sp | 22.4sp |
| 문의·버전 항목 | 15sp | -0.3sp | 21sp |
| 섹션 제목 | 13sp | -0.26sp | 18.2sp |

자간은 기존 반다라트 타이포그래피와 동일하게 글자 크기의 약 -2%, 행간은 본문 계열에 사용 중인 약 140%를 기준으로 한다. 20sp 제목은 기존 헤더 스타일에 맞춰 28sp를 사용한다.

## 검증

- 설정 바텀시트의 모든 `Text`에 크기에 맞는 `letterSpacing`과 `lineHeight`가 있는지 확인한다.
- 변경 파일이 전략 문서와 설정 바텀시트로 제한되는지 확인한다.
- `git diff --check`로 공백 오류를 확인한다.
- 실제 화면의 시각적 평가는 다음 Internal 빌드에서 확인한다.

## Internal 배포

- Play 전체 트랙의 현재 최대 versionCode `20210` 다음 값인 `2.2.11 (20211)`을 사용한다.
- Internal 릴리스 노트에는 설정 화면의 글자 간격과 줄 간격 개선을 명시한다.
- PR CI 통과 및 `main` merge 후 서명된 release AAB를 Internal Testing에 배포한다.
